# Primeor-solutions--ecommerce-Data-Analytics-Project-Excel-SQL-and-Power-BI-project


## Organisation
Primeor Solutions

## Project Overview
This project focuses on analysing e-commerce
sales data to generate meaningful business
insights using Excel, SQL and Power BI.

## Project Objectives
- Clean and prepare raw sales data.
- Analyse sales and profitability.
- Identify top-performing products.
- Evaluate customer and regional performance.
- Develop an interactive dashboard.
- Present actionable business insights.

## Tools Used
- Microsoft Excel
- MySQL
- Power BI
- GitHub
