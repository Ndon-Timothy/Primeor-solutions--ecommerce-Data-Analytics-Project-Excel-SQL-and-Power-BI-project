Primeor Solutions

## Project Overview

This project represents my E-Commerce Data Analytics Internship journey with Primeor Solutions.
The project involved analysing e-commerce transaction data, assessing data quality, extracting business insights and developing an interactive Power BI dashboard.

## Dataset Overview

- Original dataset: 51,325 rows
- Number of columns: 21
- Domain: E-commerce transactions

### Data Quality Findings

During the initial data quality assessment, I identified:

- 54 exact duplicate records.
- 54 completely blank business rows.
- 14 populated records with missing profit values.
- 2,632 sales values requiring numerical formatting standardisation.
- Additional formatting and consistency issues.

## Tools and Technologies

- Microsoft Excel
- Microsoft SQL Server (SSMS)
- Microsoft Power BI

## Project Breakdown

### Level 1: Excel – Data Cleaning and Analysis

Data quality assessment, data cleaning, calculations, PivotTables, charts, sales analysis and profitability analysis.

### Level 2: SQL Server – Data Analysis

SQL queries covering product performance, customer sales, regional and market revenue, category profitability, discount patterns and shipping analysis.

### Level 3: Power BI – Dashboard Development

An interactive three-page dashboard:

1. Executive Overview
2. Sales Analysis
3. Product and Customer Insights
