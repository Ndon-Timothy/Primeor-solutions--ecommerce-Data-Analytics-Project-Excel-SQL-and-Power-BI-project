- SQL Server – Data querying and business analysis.

## Dataset Overview
- Original dataset: 51,325 rows
- Columns: 21
- 54 exact duplicate records identified.
- 54 completely blank business rows identified.
- 14 populated records with missing profit values identified.
- 2,632 sales values requiring numerical formatting standardisation.
